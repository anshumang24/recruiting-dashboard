How to update this dashboard

Company data now lives in firms.json, separate from the code. To change a deadline, fix a status, or add a company, edit that one file in GitHub's web editor — you never touch the HTML or JS again.

Each firm has a verified date. When you check a portal yourself and confirm what's there, update that date and the verifyNote. The dashboard flags anything unchecked for 14+ days, so stale assumptions surface instead of silently rotting.

Four files must be in the repo together: index.html, style.css, app.js, firms.json, apps.json.
